# Appearance Modes

All browser chrome uses centralized semantic tokens.

## Dark
Graphite surfaces, deep backgrounds, accessible text and optional OLED black.

## Light
Neutral light surfaces, comfortable reading hierarchy and clear control states.

## Premium Glass
Frosted translucent surfaces, restrained gradients, depth and selective blur.

## Shared requirements
Persist selection; switch immediately; place picker in secondary controls; never keep a permanent theme icon on the main toolbar. Provide reduced-effects and low-memory fallbacks. Test contrast, font scaling, TalkBack and touch targets.
