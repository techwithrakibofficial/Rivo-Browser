# Development Plan

## Phase 0 — active
- Official documentation research.
- WebView/GeckoView proof-of-concept and benchmark.
- Engine ADR.
- Architecture and design-system specification.
- Security threat model.
- Modular foundation and CI.
- Foundation APK.

## Phase 1 — not authorized yet
Functional browser MVP: navigation, omnibox, tabs, private sessions, privacy controls, downloads, bookmarks, history and three themes.

## Phase 2
Tab Universe, Privacy Intelligence Center, Transfer Studio, QR, reader mode, extension workflows where verified, Developer Mode.

## Phase 3
Engine-specific features, optional sync, translation feasibility, optimization and distribution readiness.

## Exit gates
Each phase requires tests, documented limitations, known-issue review and explicit scope approval.
